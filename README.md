# 🧠 Human Analytics Engine: Decision Framework (hae-decision-framework) 🛡️

*"İlk kural kendini kandırmamaktır; ve kandırılması en kolay kişi kendinsin." — Richard Feynman*

**Human Analytics Engine (HAE)** ekosisteminin karar alma ve filtreleme modülü olan bu proje; Finans, Tıp, Yapay Zeka ve Felsefe dünyasının birbirinden bağımsız olarak icat ettiği **"Evrensel Yanılgı Savunmalarını"** cebinize taşıyan açık kaynaklı bir bilişsel kontrol (Cognitive Check-Up) uygulamasıdır.

`hae-core-app` sizi dış algoritmaların manipülasyonundan korurken, `hae-decision-framework` sizi **kendi zihninizin manipülasyonundan (Cognitive Bias)** korur.

## 🌟 Vizyon
Büyük yatırımlar yaparken, yeni bir iş kurarken veya hayat değiştiren kararlar alırken "hikayelere" değil, evrensel test mekanizmalarına güvenin. Bu uygulama, fikrinizi hayata geçirmeden önce onu 10 maddelik acımasız bir gerçeklik testinden geçirir.

## 🛠️ 10 Maddelik Evrensel Karar Anayasası
Uygulama, kararınızı şu 3 aşamalı filtreden (10 Evrensel Kural) geçirir:

**Aşama 1: Zihni Temizle**
1. **Önceden Taahhüt (Pre-commitment):** Başarı kriterini sonucu görmeden önce yaz ve kilitle. (Bilimde *Preregistration*)
2. **Dış Bakış (Base Rate):** Kendi durumuna aşık olmadan önce sektörün/genelin başarı oranına bak. 

**Aşama 2: Gerçeklikle Yüzleş (Test Et)**
3. **Yanlışlama Arayışı (Red-Teaming):** Kendi fikrini kanıtlamaya değil, çürütmeye çalış.
4. **Dokunulmamış Veri (Blind Validation):** Projeyi, fikrine aşık olmayan bağımsız bir göze/veriye test ettir.
5. **Çoklu Deneme Cezası:** Çok denediysen başarmış sayılmazsın, rastgelelik payını düş. (İstatistikte *p-hacking*)
6. **Anekdotu Reddet:** 2-3 parlak örnek kanıt değil hikayedir.
7. **Nedensel Mekanizma:** Korelasyon yetmez, mantıklı bir fiziksel/nedensel model kur.

**Aşama 3: Korunma (Hayatta Kalma)**
8. **Güvenlik Marjı (Margin of Safety):** Her şeyi doğru bilsen bile bilinmeyenler için tolerans payı bırak.
9. **Oyunda Derisi Olmak (Skin in the Game):** Tavsiye verenin yanıldığında bedel ödeyip ödemediğini test et.
10. **Zamanla İzleme:** Çalışan sistem zamanla çürür (Alpha Decay), sürekli ölç.

## 🚀 Teknoloji Yığını
- **Frontend:** Flutter (Dart)
- **Architecture:** BLoC / Provider (State Management)
- **Storage:** SQLite / SharedPreferences (Local-First, Sıfır Bulut Gizliliği)
- **UI/UX:** Minimalist, odaklanmaya dayalı "Sihirbaz (Wizard)" tasarımı.

## 📥 Kurulum
```bash
# Depoyu klonlayın
git clone https://github.com/human-analytics-engine/hae-decision-framework.git

# Bağımlılıkları yükleyin
flutter pub get

# Uygulamayı çalıştırın
flutter run
```
